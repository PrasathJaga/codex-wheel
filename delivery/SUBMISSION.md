# Codex Wheel — reviewer start here

**A successful response can hide an incorrect business outcome.** Codex Wheel uses
Meta to investigate supported code changes, select a bounded experiment and explain
execution evidence. Independent checks inspect committed effects and verify a
bounded restoration.

## Open the report in under a minute

Download `index.html` from this directory and open it in a current browser. No API
key, Docker, Java, Python or account connection is needed to view the downloaded
report. The self-contained file makes no network request until a viewer follows an
external evidence link. It is recorded evidence, not a live investigation console.

Use **Before repair / After repair**, inspect actual trial data and source
references, and try the optional exposure calculator. File viewing avoids GitHub
Actions artifact egress quotas. The repository HTML view shows source; use its
**Download raw file** control to open the report locally.

The downloadable submission package also includes the captioned three-minute MP4,
script, provenance index and authenticated original evidence archives. A Library
copy is provided for preservation; it is not a public judge-accessible video URL.

## Reproduce the archive audit

Use a full repository checkout because historical source-admission tests inspect
pinned Git objects. A source ZIP is enough to view the report but not those tests.
From the repository root, with Python 3.11+:

```bash
python -m pip install -e './services/support-agent-python[test]'
python -m wheel.two_domain_report --refund /path/fresh-pr-cycle-v2.zip --inventory /path/inventory-repair-v1.zip --failure /path/fresh-pr-cycle-failure.zip --output /tmp/dashboard.html
python -m delivery.build_submission --refund /path/fresh-pr-cycle-v2.zip --inventory /path/inventory-repair-v1.zip --failure /path/fresh-pr-cycle-failure.zip --generic /path/generic-meta-integration-v1.zip --output /tmp/submission-report
```

These commands authenticate existing archives and recompute checks. They make no
new Meta requests or business execution worlds. Missing/corrupt inputs fail; a
changed archive is not silently substituted. Fresh execution requires the separate
supported workflow/runtime setup and is not performed by opening this report.
